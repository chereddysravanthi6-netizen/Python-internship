# Task 5 - Data Analysis on CSV Files

## Objective
Analyze sales data from a CSV file using Python and Pandas.

## Tools Used
- Python 3
- Pandas
- Matplotlib
- Jupyter Notebook / Google Colab

## Features
- Load CSV file
- Display dataset information
- Find total sales
- Group data using `groupby()`
- Create bar chart
- Display basic data insights

## Project Files
- analysis.ipynb
- sales_data.csv
- README.md

## Requirements

Install the required libraries:

```bash
pip install pandas matplotlib
```

## How to Run

1. Open Jupyter Notebook or Google Colab.
2. Open `analysis.ipynb`.
3. Place `sales_data.csv` in the same folder.
4. Run all notebook cells.

## Sample Output
- Dataset loaded successfully
- Total sales calculated
- Sales by category displayed
- Bar chart generated

## Concepts Used
- Pandas DataFrame
- CSV File Handling
- groupby()
- sum()
- Data Visualization
